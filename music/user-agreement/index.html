一刻音乐由张佳宾（以下简称“我们”）提供与维护。

本《一刻音乐用户服务协议》（以下简称“本协议”）是您与我们就下载、安装、访问或使用一刻音乐及相关功能所订立的协议。

2. 协议范围、目的及确认方式

本协议适用于一刻音乐在 HarmonyOS 设备上提供的本地音乐导入或引用、曲库整理、音乐播放、歌词查看、歌单与收藏管理，以及向已连接手表传送音乐和局域网文件接收等功能。

请您在使用一刻音乐前仔细阅读本协议，特别是以加粗形式提示的内容。

您下载、安装、访问或实际使用一刻音乐，即表示您已阅读并同意本协议；如您不同意本协议，请停止使用相关服务。使用具体功能时如页面另有说明或需要您单独授权，请一并阅读并遵循相应提示。

一刻音乐个人信息的处理方式见《关于一刻音乐与隐私的声明》。

3. 使用本服务的要求

3.1 您应当具备与使用本服务相适应的民事行为能力。未成年人应在监护人的指导下阅读本协议，并在取得监护人同意后使用本服务。

3.2 您应确保对导入、引用、整理、播放或传送的音乐、歌词、封面及其他文件具有合法来源或必要的权利、授权。您应遵守适用法律法规以及相关权利人的合法权益。

3.3 您应按照 HarmonyOS 系统提示使用文件选择、设备连接和网络等系统能力，并自行确认设备、文件和传送目标符合您的使用需求。

4. 服务内容

一刻音乐是一款 HarmonyOS 本地音乐播放器。您可以通过系统文件选择能力导入音乐，或引用设备上可访问的外部音乐文件；也可以在本机整理曲库、歌单和收藏，播放音乐并查看可用的歌词和歌曲信息。

对外部引用文件，一刻音乐按只读来源处理；复制导入或通过设备接收的文件副本保存在应用空间。不同设备、文件格式及系统版本可能影响文件识别、歌词显示或播放效果。

在您主动选择已连接的手表并发起传送后，一刻音乐可通过 HarmonyOS 设备连接能力向该设备发送所选音乐及其关联资料。传送能力受设备兼容性、系统服务和连接状态影响。

您主动开启局域网接收后，可从同一局域网内的浏览器或其他发送端向本机发送音乐文件。该接收服务仅在您开启时提供，并会在应用进入后台时停止。

一刻音乐不提供在线音乐曲库、在线音乐播放、账号体系、云端曲库或云同步、广告或付费订阅服务。除本协议及隐私声明明确说明的功能外，请勿将本地记录理解为云端备份。

5. 用户使用规则

5.1 请您妥善选择和管理导入、引用、删除、导出及传送的文件，并在删除或卸载应用前自行备份仍需保留的原始音乐及其他资料。删除应用内副本或曲库记录不会当然删除外部引用所指向的原文件；卸载或清除应用数据可能导致应用空间中的副本、索引、播放记录和设置无法恢复。

5.2 您不得利用一刻音乐导入、保存、播放或传送侵犯他人著作权、隐私权或其他合法权益的内容，也不得未经授权向他人传播受保护的音乐或文件。

5.3 局域网接收使用未加密的 HTTP 连接，PIN 或传输票据不等同于网络加密。请仅在您信任的局域网中开启接收，并在完成后关闭；同一网络中的其他设备可能观察到或访问传输内容。

5.4 设备传送前请核对目标设备与待发送内容。因您选择错误文件或设备、设备故障、存储空间不足、系统限制、网络中断或其他非我们合理控制的原因造成传送失败或资料丢失的，请您通过原始文件或已有备份恢复。

一刻音乐依赖 HarmonyOS 系统能力、设备兼容性、文件格式、存储空间及设备连接状态。系统升级、系统服务调整、设备差异或网络环境变化可能导致部分功能的显示、识别、传输或播放效果发生变化。

我们会在合理范围内维护应用功能并处理已知问题。因操作系统、设备、网络或其他我们无法合理控制的情况造成的临时中断、延迟或功能不可用，我们将在合理范围内协助排查。

本协议不免除或限制法律规定不得免除或限制的责任，也不限制您依法享有的权利。
